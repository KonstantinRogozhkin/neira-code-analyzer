### 🚀 Quick Performance Win
**Проблема:** Недостаточно агрессивные фильтры по умолчанию

**Результат:** Автоматическое снижение потребления токенов на 10-40% для большинства проектов

### 🔧 Quick Error Fix  
**Проблема:** Потенциально неверная статистика в `analyze_filters`  
**Решение:** Добавлено явное предупреждение о неполной детальной статистике  
**Результат:** Пользователи четко информированы о надежности данных

### 1️⃣ Критический приоритет
**Проблема:** Некорректная статистика в `analyze_filters`  
**Решение:** Удалена фоллбэк-логика, которая "угадывала" статистику  
**Результат:** Честная отчетность - если детальная информация недоступна, об этом сообщается явно

### 2️⃣ Высокий приоритет  
**Проблема:** Разрастание отладочных точек входа  
**Решение:** 
- Создан универсальный `tools/debug_main.py` с двумя режимами (simple/minimal)
- Удалены `src/neira_code_analyzer/simple_main.py` и `tools/minimal_main.py`
- Консолидирован отладочный функционал в одном файле  
**Результат:** Упрощенная отладка, единая точка входа для тестирования

### 5️⃣ Низкий приоритет
**Проблема:** Избыточный модуль `ai.py` (прокси к `ai_utils.py`)  
**Решение:** Удален модуль `ai.py`, который только ре-экспортировал функции  
**Результат:** Упрощена навигация по коду, устранен лишний уровень абстракции

### 4️⃣ Средний приоритет (Частично решено)

**Решение:** Подтверждено, что `mcp_schemas.py` уже использует композицию схем
