# Performance Tests

Тесты производительности и бенчмарки для критически важных операций.

## Что тестируем

- Скорость анализа больших кодовых баз
- Время генерации контекста
- Производительность фильтрации файлов
- Потребление памяти при работе с большими проектами
- Время отклика MCP операций

## Структура

```
tests/performance/
├── test_analysis_performance.py    # Производительность анализа
├── test_filtering_performance.py   # Скорость фильтрации
├── test_memory_usage.py           # Тесты потребления памяти
├── benchmarks/                    # Данные для бенчмарков
└── reports/                       # Отчеты производительности
```

## Запуск

```bash
# Все performance тесты (медленные!)
pytest tests/performance/ -v --tb=short

# С ограничением времени
pytest tests/performance/ -v --maxfail=1 --timeout=300

# Только быстрые performance тесты
pytest -m "performance and not slow" -v
```

## Требования

- Время выполнения: < 5 мин для полного suite
- Маркировка slow тестов (> 30 сек)
- Сохранение результатов в reports/
- Сравнение с предыдущими результатами

## Пороговые значения

- **Анализ кода:** < 10 сек для проектов до 1000 файлов
- **Генерация контекста:** < 5 сек для проектов до 500 файлов  
- **Фильтрация:** < 1 сек для проектов до 10000 файлов
- **Потребление памяти:** < 500 MB для проектов до 5000 файлов

## Маркеры

- `@pytest.mark.performance` - все performance тесты
- `@pytest.mark.slow` - медленные тесты (> 30 сек)
- `@pytest.mark.memory` - тесты потребления памяти
- `@pytest.mark.benchmark` - бенчмарки для сравнения
