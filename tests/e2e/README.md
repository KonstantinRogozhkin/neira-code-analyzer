# E2E (End-to-End) Tests

Полные пользовательские сценарии, тестирующие работу системы от начала до конца.

## Что тестируем

- Полные пользовательские workflow'ы
- Интеграцию с внешними сервисами (Neira API)
- Реальные MCP-сценарии
- UI/UX потоки (если применимо)

## Структура

```
tests/e2e/
├── test_mcp_workflows.py       # Основные MCP сценарии
├── test_neira_integration.py   # Интеграция с Neira API
├── test_user_journeys.py       # Полные пользовательские путешествия
└── fixtures/                  # Тестовые данные для E2E
```

## Запуск

```bash
# Все E2E тесты
pytest tests/e2e/ -v

# Отдельный тест
pytest tests/e2e/test_mcp_workflows.py -v

# С маркером
pytest -m "e2e" -v
```

## Требования

- Время выполнения: < 30 сек на тест
- Используют реальные (или близкие к реальным) данные
- Независимы друг от друга
- Содержат cleanup после выполнения

## Примеры тестов

1. **MCP Tool Discovery** - проверка доступности инструментов
2. **Code Analysis Workflow** - полный цикл анализа кода
3. **Filter Optimization** - процесс оптимизации фильтров
4. **Documentation Generation** - генерация документации
