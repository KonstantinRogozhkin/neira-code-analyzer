# 📚 Коллекция шаблонов 

Эта папка содержит набор специализированных Handlebars шаблонов для различных сценариев анализа кода с помощью neira-code-analyzer.

## 🎯 Доступные шаблоны

### 🔍 **code-review.hbs** - Анализ кода для Code Review
Структурированный шаблон для проведения ревью кода с фокусом на качество и стандарты.

**Использование:**
```bash
# Через MCP
template: "$(cat templates/code-review.hbs)"

# Через CLI (если доступен)
code2prompt /path/to/project -t templates/code-review.hbs
```

**Особенности:**
- ✅ Проверка соответствия стандартам
- ✅ Выявление потенциальных багов
- ✅ Оценка производительности
- ✅ Анализ принципов SOLID/DRY
- ✅ Приоритизированные рекомендации

## 🚀 Как использовать шаблоны

### Через MCP сервер (рекомендуется):
```python
# Пример использования в Cursor/Claude
await mcp_code2prompt_get_context(
    path="/path/to/project",
    include_patterns=["*.py", "*.js"],
    template="""$(cat templates/code-review.hbs)"""
)
```

### Через Python SDK:
```python
from code2prompt_rs import Code2Prompt

# Загрузка шаблона
with open('templates/security-audit.hbs', 'r') as f:
    template = f.read()

# Использование
prompt = Code2Prompt(path="/path/to/project")
result = prompt.generate(template=template)
print(result.prompt)
```

### Через CLI (если установлен code2prompt):
```bash
code2prompt /path/to/project -t templates/refactoring.hbs
```

## 🎨 Создание собственных шаблонов

### Доступные переменные Handlebars:

#### 📊 Метаданные проекта:
- `{{absolute_code_path}}` - полный путь к проекту
- `{{directory_name}}` - имя директории проекта  
- `{{files_count}}` - количество файлов
- `{{total_size}}` - общий размер в байтах
- `{{token_count}}` - количество токенов

#### 🗂️ Структура:
- `{{source_tree}}` - дерево файлов и папок

#### 📋 Файлы:
- `{{#each files}}` - итерация по файлам
  - `{{path}}` - путь к файлу
  - `{{size}}` - размер файла в байтах
  - `{{extension}}` - расширение файла
  - `{{code}}` - содержимое файла

### Условная логика:
```handlebars
{{#if code}}
  Файл содержит код
{{/if}}

{{#ifCond extension "==" "py"}}
  Это Python файл
{{/ifCond}}
```

### Пример простого шаблона:
```handlebars
# Анализ проекта {{directory_name}}

## Структура:
{{source_tree}}

## Файлы:
{{#each files}}
### {{path}}
{{#if code}}
```{{extension}}
{{code}}
```
{{/if}}
{{/each}}
```

## 🔧 Настройка и оптимизация

### Для больших проектов:
Используйте фильтры для ограничения анализа:
```python
include_patterns=["*.py", "*.js"],  # Только нужные типы файлов
exclude_patterns=["**/node_modules/**", "**/venv/**"],  # Исключить зависимости
```

### Для конкретных задач:
Комбинируйте шаблоны или создавайте специализированные версии:
- **Быстрый ревью:** используйте `code-review.hbs` только на измененных файлах
- **Security focus:** комбинируйте `security-audit.hbs` с фильтрами на конфиг файлы
- **Performance critical:** используйте `performance-analysis.hbs` на core модулях
