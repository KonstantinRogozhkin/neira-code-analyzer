# Документация neira-code-analyzer

## 🎯 Обзор

**neira-code-analyzer** — это продвинутый MCP-сервер для анализа кодовых баз, использующий мощь Google Gemini для предоставления глубокого анализа и автоматических рекомендаций по улучшению кода.

Ключевые возможности включают **интерактивные сессии анализа**, **JSON-контракт с ИИ** и **автоматическое применение исправлений**.

## 🛠️ Основные инструменты

| Инструмент | Описание | Пример использования |
|------------|----------|----------------------|
| `get_analyze` | ⭐ **(Флагман)** Полный интерактивный AI-анализ кода. Используйте `"session_id"` для продолжения диалога. | `{"path": ".", "template_name": "code-review", "user_query": "Найди проблемы с производительностью.", "session_id": "20241213_143022"}` |
| `get_context` | 📄 Генерация контекста кодовой базы для ИИ. | `{"path": ".", "template_name": "documentation"}` |
| `analyze_filters` | 🔍 Анализ и оптимизация файловых фильтров. | `{"path": ".", "preset_name": "default"}` |
| `get_templates` | 📋 Получение списка доступных шаблонов анализа. | `{}` |

## 🏗️ Архитектура (Версия 2.0)

Проект использует современную асинхронную архитектуру, построенную на следующих принципах:

- **🧠 JSON API Contract:** Строгое определение формата взаимодействия с ИИ.
- **🛡️ Fail-Fast:** Немедленное прерывание работы при критических ошибках.
- **🔄 Асинхронность:** Неблокирующие операции для максимальной производительности.
- **🎯 Single Responsibility Principle (SRP):** Каждый компонент решает одну задачу.

Подробнее см. в **[Архитектурном обзоре](guides/architecture/overview.md)**.
