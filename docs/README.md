# Документация neira-code-analyzer

## 🎯 Обзор

neira-code-analyzer - продвинутый MCP сервер для анализа кода с AI поддержкой. Интегрируется с Google Gemini для профессионального анализа кодовых баз через Model Context Protocol.

## 🛠️ Инструменты

### 🔥 Основные (флагманские)
- **`get_analyze`** - автоматический AI анализ кода
- **`get_context`** - генерация контекста для анализа
- **`gen_docs`** - автоматическая генерация документации

### ⚙️ Утилиты
- **`set_filters`** - настройка фильтров проекта  
- **`get_templates`** - просмотр доступных шаблонов
- **`manage_presets`** - управление пресетами фильтров

## 🏗️ Архитектура

Проект следует принципам **SOLID** с упрощенной архитектурой:
- **Модульность** - каждый компонент имеет единственную ответственность
- **Простота** - отказ от DI-контейнеров в пользу прямых зависимостей  
- **Безопасность** - типизированные контракты и безопасная обработка путей
- **Производительность** - оптимизированные фильтры для современных фреймворков

## 🤖 AI интеграция

- **Провайдер:** Google AI (Gemini)
- **Модели:** gemini-2.5-pro-preview-06-05, gemini-2.0-flash, gemini-1.5-pro
- **Протокол:** Model Context Protocol (MCP)
