# ⚠️ Устаревшая документация

Этот файл содержит устаревшие инструкции по работе с фильтрами.

## 🔄 Актуальная документация

Пожалуйста, используйте актуальные руководства:

### 📚 Основные руководства:
- **[Быстрый старт](help/quickstart.md)** - начало работы с проектом
- **[Руководство по фильтрам](guides/features/filtering.md)** - современная система фильтрации

### 🎯 Рекомендуемые инструменты:
1. **`get_analyze`** - полный автоматический AI анализ кода ⭐ **Рекомендуется**
2. **`set_filters`** - настройка фильтров с пресетами
3. **`get_context`** - генерация контекста для ручного анализа

### 💡 Быстрое начало:

```bash
# Автоматический анализ Python проекта
get_analyze --path /path/to/project --preset_name python-project --template_name code-review

# Анализ React приложения
get_analyze --path /path/to/project --preset_name react-app --template_name code-review

# Настройка фильтров для конкретного проекта
set_filters --path /path/to/project --preset_name default
```
