# 🎯 set_filters - Автоматическая настройка фильтров проекта

## Описание

`set_filters` - это новый инструмент neira-code-analyzer, который автоматически подбирает оптимальные фильтры для вашего проекта и сохраняет их в файл `.neira` в корне проекта.

## 🎯 Цель

**Настроить проект с оптимальными фильтрами один раз и использовать везде.**

Вместо того чтобы каждый раз указывать фильтры вручную, `set_filters`:
1. Анализирует структуру проекта
2. Автоматически определяет тип проекта (Python, React, etc.)
3. Применяет подходящие фильтры
4. Сохраняет конфигурацию в `.neira`

## 🚀 Использование

### Автоматическая настройка (рекомендуется)

```json
{
  "path": "/path/to/your/project"
}
```

Инструмент автоматически:
- Определит тип проекта (Python, React, Web App, etc.)
- Применит соответствующий пресет фильтров
- Сохранит конфигурацию

### С указанием конкретного пресета

```json
{
  "path": "/path/to/project",
  "preset_name": "python-project"
}
```

### Пресет + дополнительные файлы

```json
{
  "path": "/path/to/project", 
  "preset_name": "python-project",
  "merge_with_preset": true,
  "include_patterns": ["*.md", "*.txt"]
}
```

### Полностью пользовательские фильтры

```json
{
  "path": "/path/to/project",
  "include_patterns": ["*.py", "*.js"],
  "exclude_patterns": ["tests/**", "temp/**"]
}
```

## 📁 Результат

После выполнения в корне проекта создается файл `.neira`:

```json

  "project_path": "/path/to/project",

```

## 🤖 Автоопределение типов проектов

| Тип проекта | Определяется по | Применяемый пресет |
|-------------|-----------------|-------------------|
| **Python** | `pyproject.toml`, `requirements.txt`, `setup.py`, `*.py` файлы | `python-project` |
| **React/Next.js** | `package.json` с зависимостями `react`/`next` | `react-app` |
| **Electron** | `package.json` с зависимостью `electron` | `electron-app` |
| **Web App** | `package.json` (общий случай) | `web-app` |
| **Другие** | По умолчанию | `code-only` |

## 💡 Преимущества

1. **Один раз настроил - везде работает**: Другие инструменты neira-code-analyzer автоматически используют сохраненные фильтры
2. **Командная работа**: Добавьте `.neira` в git для единых настроек в команде
3. **Оптимизация**: Автоматически исключает ненужные файлы (node_modules, dist, __pycache__, etc.)
4. **Гибкость**: Можно комбинировать пресеты с пользовательскими паттернами

## 🔧 Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `path` | string | Путь к проекту (обязательный) |
| `preset_name` | string | Пресет фильтров (опционально, автоопределяется) |
| `include_patterns` | array | Дополнительные паттерны включения |
| `exclude_patterns` | array | Дополнительные паттерны исключения |
| `merge_with_preset` | boolean | Объединить с пресетом (true) или заменить (false) |
| `encoding` | string | Кодировка для токенов: cl100k, p50k, gpt2 |

## 📋 Доступные пресеты

- `python-project` - Python проекты
- `web-app` - Веб-приложения (общий)
- `react-app` - React/Next.js приложения
- `electron-app` - Electron приложения
- `code-only` - Только исходный код
- `aggressive` - Максимальное исключение файлов

## 🎯 Интеграция с другими инструментами

После настройки фильтров через `set_filters`, другие инструменты neira-code-analyzer будут автоматически использовать сохраненную конфигурацию:

```bash
# Анализ с сохраненными фильтрами
get_context --load-project-filters
code_review --load-project-filters
```

## ⚠️ Важные моменты

1. **Файл `.neira`** создается в корне проекта
2. **Рекомендуется** добавить этот файл в git для командной работы
3. **Автоопределение** работает по наличию характерных файлов в проекте
4. **Перезапись**: Повторный вызов `set_filters` перезапишет существующую конфигурацию

## 🔄 Замена analyze_filters

`set_filters` заменяет старый инструмент `analyze_filters`, предоставляя:
- Более простой интерфейс
- Автоматическое сохранение конфигурации
- Интеграцию с другими инструментами
- Фокус на практическом результате вместо анализа
