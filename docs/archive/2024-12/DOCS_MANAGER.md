Инструкция по созданию и актуализации документации

1. Цели
Извлекать знания из  отчётов из docs/fixes/ и  docs/changelog/ и других md файлов и формировать из них документации а использованные перемещать в архив. Хранить «сырьё» только в docs/archive/ (в .gitignore). 
Найти список изменений по git и дополнять гайды и обновлять документацию в связи с последними изменениями.


2. Структура

/ ← в корене проекта бывают .md файлы, документы, извлекай оттуда суть и удаляй не нужные md
docs
├── README.md              ← Обновляй этот файл
├── changelog              ← Добавляй сюда свежие изменения
│   ├── CHANGELOG.md
│   └── major-fixes.md              ← Добавляй сюда свежие изменения
├── features              ← извлекай оттуда знаищай от историиния суть и очищай от истории (папка должна по итогу быть пустой после извлечения знаний)
├── fixes              ← извлекай оттуда знаищай от историиния суть и очищай от истории (тоже пустая после извлечения должна быть)
├── guides              ← guides for tech users
│   ├── architecture
│   ├── features
│   ├── ops
│   └── setup
├── help           ← guides for non- tech users
└── archive/           ← вне Git (в .gitignore)

3. Цикл: Найти сырые материалы → Извлечь знания → Убедиться что они актуальные и применимы сейчас → Сжать и добавить знания в docs в нужную папку создать или обновить файлы.

Шаг	Что делаем	Инструмент	Выход
1. Скан 	Найти все новые / длинные файлы (> 400 строк)	find docs -name '*.md' -exec wc -l {}	список кандидатов
2. Дубликаты	Проверить, есть ли уже похожий гайд	grep -Ri "<ключ>" docs/guides	метка «merge»/«new»
3. Сжатие	• Оставить «проблема → решение → результат» • Цель ≤ 150 строк	любой редактор	обновлённый .md
4. Контроль	a) wc -l подтвердить ≤ 150b) открыть файл и глазами убедиться, что хвосты удалены	терминал + просмотр	✓
5. Перемещение	git mv docs/fixes/file.md docs/archive/2025-06/	git	fixes/ пуст
6. README-TOC	npx markdown-toc -i docs/README.md	markdown-toc	актуальное TOC
7. Link-check	markdown-link-check -q docs/**/*.md	link-checker	ошибок 0
8. Git-log sweep	git log --since='2 weeks ago' --pretty='%h %s'Отфильтровать по feat: perf: breaking:	grep / ctrl+F	список фактов
9. Добавить факты	Если факт НЕ фигурирует в guides/changelog → • дописать 1-2 строки в подходящий файл• добавить ссылку [abc123]	редактор	знания вынесены из истории
10. Commit	Семантическое сообщение docs: cycle 2025-06-09	git	чистый diff
