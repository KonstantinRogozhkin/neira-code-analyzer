# Руководство по контрибьюции

Мы рады, что вы хотите внести свой вклад в Neira Code Analyzer! Любая помощь приветствуется.

## Как внести вклад

### Сообщения об ошибках (Bug Reports)

*   Убедитесь, что ошибка еще не была зарегистрирована в разделе Issues.
*   Четко опишите проблему, шаги для воспроизведения, ожидаемое и фактическое поведение.
*   Укажите версию программы и ваше окружение (ОС, версия Python и т.д.).

### Предложения по улучшению (Feature Requests)

*   Опишите, какую проблему решает ваше предложение и почему это важно.
*   Подробно объясните, как, по вашему мнению, должна работать новая функция.

### Процесс разработки (Pull Requests)

1.  **Форкните репозиторий.**
2.  **Создайте новую ветку** для ваших изменений (`git checkout -b feature/amazing-feature`).
3.  **Внесите изменения.** Пишите понятный и чистый код.
4.  **Добавьте тесты** для новой функциональности.
5.  **Обновите документацию**, если это необходимо.
6.  **Убедитесь, что все тесты проходят.**
7.  **Создайте Pull Request.** Опишите внесенные изменения и свяжите PR с соответствующим Issue, если он есть.

## Стиль кода

Мы придерживаемся стандарта **PEP 8** для кода на Python. Пожалуйста, используйте линтеры, такие как `flake8` или `black`, чтобы ваш код соответствовал стилю проекта.

Спасибо за ваш вклад!
