# Руководство по контрибьюции

Мы рады, что вы хотите внести свой вклад в развитие **Neira Code Analyzer**! Любая помощь приветствуется.

## Как можно помочь?

- **Сообщения об ошибках (Bug Reports)**: Если вы нашли ошибку, пожалуйста, создайте issue с подробным описанием.
- **Предложения по улучшению (Feature Requests)**: У вас есть идея, как сделать проект лучше? Расскажите нам о ней.
- **Pull-реквесты (Pull Requests)**: Вы можете исправить ошибку или реализовать новую функциональность самостоятельно.

## Процесс создания Pull-реквеста

1.  **Форкните репозиторий**: Создайте свою копию проекта.
2.  **Создайте новую ветку**: `git checkout -b feature/ваша-новая-фича`.
3.  **Внесите изменения**: Напишите код и тесты к нему.
4.  **Сделайте коммит**: `git commit -m "feat: добавлена новая фича"`. Мы придерживаемся [Conventional Commits](https://www.conventionalcommits.org/).
5.  **Отправьте изменения в ваш форк**: `git push origin feature/ваша-новая-фича`.
6.  **Создайте Pull-реквест**: В основном репозитории проекта создайте Pull Request из вашей ветки.

## Стиль кода

Пожалуйста, придерживайтесь стиля кода, принятого в проекте. Перед созданием Pull-реквеста убедитесь, что все тесты проходят успешно.

Спасибо за ваш вклад!
