# Руководство по контрибьюции

Мы рады, что вы хотите внести свой вклад в развитие проекта Neira Code Analyzer! Это руководство поможет вам сделать процесс максимально простым и эффективным.

## Как можно помочь?

Вы можете помочь проекту следующими способами:
- Сообщать об ошибках (Bug a report).
- Предлагать новые функции (Feature request).
- Улучшать документацию.
- Писать код и отправлять Pull Request'ы.

## Сообщения об ошибках

- Убедитесь, что ошибка еще не была зарегистрирована в разделе Issues.
- Четко опишите шаги для воспроизведения ошибки.
- Укажите вашу операционную систему, версию проекта и другие важные детали окружения.

## Процесс разработки

1. **Форкните репозиторий**: Сделайте форк основного репозитория проекта.
2. **Создайте ветку**: `git checkout -b feature/название-вашей-фичи` или `git checkout -b fix/описание-фикса`.
3. **Внесите изменения**: Напишите код и тесты к нему.
4. **Сделайте коммит**: `git commit -m "feat: краткое описание изменений"`. Мы придерживаемся [Conventional Commits](https://www.conventionalcommits.org/).
5. **Отправьте изменения в свой форк**: `git push origin feature/название-вашей-фичи`.
6. **Создайте Pull Request**: Откройте Pull Request из вашей ветки в ветку `main` основного репозитория.

## Стиль кода

Пожалуйста, придерживайтесь стиля кода, используемого в проекте. Для Python это [PEP 8](https://www.python.org/dev/peps/pep-0008/).

Спасибо за ваш вклад!
