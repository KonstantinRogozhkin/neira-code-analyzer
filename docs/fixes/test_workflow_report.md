## 🔥 Критические проблемы

### 1. AI тесты вызывают реальные API (Unit Tests)
**Файл**: `tests/unit/test_ai_utils.py`

**Проблемы**:
- Тесты не используют моки - вызывают реальный Google AI API
- Получают реальные ответы вместо ожидаемых мок-данных
- Тесты на обработку ошибок не работают

**Примеры провалов**:
```python
# Ожидалось: 'Test AI analysis response'
# Получено: 'Of course. This is a fascinating and classic "meta" prompt...' (полный AI ответ)

# Ожидалось: ValueError('API ключ не найден')
# Получено: Нет ошибки - API работает
```

### 2. Интеграционные тесты - API несоответствия
**Файл**: `tests/integration/test_analysis_session.py`

**Проблемы**:
- `AnalysisSessionManager.create_new_session()` требует дополнительные параметры
- Отсутствует атрибут `interaction_history` в `AnalysisSessionState`
- Метод `continue_session` не существует
- Неправильные статусы сессий (`'analyzing'` вместо `'active'`)
