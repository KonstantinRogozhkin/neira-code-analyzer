# 🧪 Тестирование neira-code-analyzer

**Версия: 1.0 (Декабрь 2024)**

Этот документ описывает, как запускать тесты и работать с системой тестирования в проекте `neira-code-analyzer`.

## 🎯 Цели системы тестирования

- **Проверка архитектурных улучшений:** Убедиться, что новые компоненты (`AnalysisAgent`, `SessionManager` и др.) работают корректно.
- **Предотвращение регрессий:** Гарантировать, что старые ошибки, такие как "тихие отказы", не появляются снова.
- **Обеспечение качества кода:** Поддерживать стабильность и надежность на высоком уровне.

---

## 🛠️ Инструменты

- **`pytest`**: Основной фреймворк для написания и запуска тестов.
- **`pytest-asyncio`**: Расширение для тестирования асинхронного кода.
- **`pytest-cov`**: Используется для измерения покрытия кода тестами.
- **`unittest.mock`**: Для создания моков и изоляции зависимостей.

## 🚀 Как запускать тесты

Все команды следует выполнять из корня проекта.

### 1. Запуск всех тестов
Эта команда выполнит все тесты во всех категориях.

```bash
uv run python -m pytest tests/ -v
```

### 2. Запуск только быстрых тестов
Юнит-тесты и регрессионные тесты работают быстро и не требуют внешних зависимостей.

```bash
uv run python -m pytest tests/unit/ tests/regression/ -v
```

### 3. Запуск тестов с отчетом о покрытии
Эта команда сгенерирует отчет о покрытии кода в формате HTML, который можно найти в директории `htmlcov/`.

```bash
uv run python -m pytest tests/ --cov=src --cov-report=html
```
