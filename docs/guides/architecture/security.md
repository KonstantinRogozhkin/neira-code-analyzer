# Безопасность системы

## 🔒 Ключевые компоненты безопасности

### Path Validation (Валидация путей)
**Проблема:** Path traversal атаки (../../../etc/passwd)  
**Решение:** Модуль `path_validator.py`  
**Результат:** 100% защита от выхода за пределы проекта

### API Security (Безопасность API)
**Проблема:** Утечка API ключей в репозиторий  
**Решение:** Паттерны в `.gitignore`: `.env*`, `**/.env*`, `*.key`  
**Результат:** Защита от случайного коммита секретов

### DoS Protection (Защита от DoS)
**Проблема:** Обработка файлов неограниченного размера  
**Решение:** Лимиты `MAX_FILE_SIZE_BYTES = 10MB`, `MAX_FILES_COUNT = 10000`  
**Результат:** Предотвращение исчерпания ресурсов

### Rate Limiting (Ограничение запросов)
**Проблема:** Spam запросы к AI API  
**Решение:** `asyncio.Semaphore(5)` в `AIClientSingleton`  
**Результат:** Максимум 5 одновременных запросов

## 🛡️ Архитектурная безопасность

### Thread Safety
- **ServiceContainer** с RLock для многопоточности
- Замена небезопасного глобального кэша
- Singleton паттерн с блокировками

### Error Handling 
- Централизованная обработка через `error_handling.py`
- Fail-fast подход
- Стандартизированные error responses

### Container Security
- Непривилегированный пользователь в Docker
- Healthcheck для мониторинга
- Set -e для прерывания при ошибках
