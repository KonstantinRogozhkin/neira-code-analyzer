# Шаблоны Анализа - neira-code-analyzer

Полное руководство по профессиональным шаблонам анализа кода в `neira-code-analyzer`.

## 🎯 Обзор шаблонов

`neira-code-analyzer` предоставляет 7 профессиональных шаблонов, каждый из которых оптимизирован для конкретных типов анализа:

| Шаблон | Назначение | Лучше всего для |
|--------|------------|-----------------|
| `code-review` | Всесторонний анализ кода | Code review, общий анализ |
| `security-audit` | Аудит безопасности | Поиск уязвимостей, security review |
| `documentation` | Создание документации | API docs, README, guides |
| `refactoring` | План рефакторинга | Legacy код, техдолг |
| `performance-analysis` | Анализ производительности | Оптимизация, узкие места |
| `migration-guide` | Планирование миграции | Переход на новые технологии |
| `api-documentation` | API документация | REST API, GraphQL, библиотеки |

---

## 📋 Подробное описание шаблонов

### 1. `code-review` - Комплексный Code Review ⭐

**Самый популярный шаблон** для всестороннего анализа кода.

#### Что анализирует:
- ✅ **Качество кода**: читаемость, структура, best practices
- 🔒 **Безопасность**: потенциальные уязвимости
- ⚡ **Производительность**: узкие места, оптимизации
- 🧪 **Тестируемость**: покрытие тестами, мокирование
- 📚 **Документация**: комментарии, docstrings
- 🏗️ **Архитектура**: паттерны, SOLID принципы

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/web-api",
  "template_name": "code-review",
  "user_query": "Проведи детальный code review с фокусом на безопасность и производительность",
  "ai_model": "gemini-2.5-pro-preview-06-05"
}
```

#### Результат включает:
- 📊 Общую оценку качества кода
- 🚨 Критические проблемы и их решения
- 💡 Рекомендации по улучшению
- 🔧 Конкретные исправления кода

---

### 2. `security-audit` - Аудит Безопасности 🔒

Специализированный шаблон для комплексного анализа безопасности.

#### Фокус анализа:
- 🛡️ **Уязвимости**: SQL-инъекции, XSS, CSRF
- 🔐 **Аутентификация**: слабые пароли, токены
- 🔑 **Авторизация**: права доступа, эскалация
- 📡 **Сетевая безопасность**: TLS, шифрование
- 💾 **Безопасность данных**: утечки, валидация
- 🏛️ **Compliance**: GDPR, PCI DSS, OWASP

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/banking-app",
  "template_name": "security-audit",
  "user_query": "Найди все потенциальные уязвимости безопасности в банковском приложении",
  "max_tokens": 1000000
}
```

#### Результат включает:
- 🚨 Классификацию угроз по критичности
- 🔧 Конкретные исправления уязвимостей
- 📋 Чек-лист проверок безопасности
- 🛡️ Рекомендации по защите

---

### 3. `documentation` - Генерация Документации 📚

Создание всех видов технической документации.

#### Создает:
- 📖 **API Reference**: описание endpoints, параметров
- 🚀 **README**: установка, использование, примеры
- 🏗️ **Architecture docs**: диаграммы, компоненты
- 💡 **Tutorials**: пошаговые руководства
- ❓ **FAQ**: частые вопросы и ответы
- 📋 **Changelog**: история изменений

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/ml-library",
  "template_name": "documentation",
  "user_query": "Создай полную документацию для ML библиотеки с примерами и API reference"
}
```

#### Результат включает:
- 📄 Структурированную документацию
- 💻 Примеры кода с комментариями
- 🔗 Внутренние ссылки и навигацию
- 🎨 Markdown форматирование

---

### 4. `refactoring` - План Рефакторинга 🔄

Анализ legacy кода и создание плана модернизации.

#### Анализирует:
- 🏗️ **Архитектурные проблемы**: monolith, tight coupling
- 💸 **Технический долг**: устаревший код, хаки
- 🔄 **Code smells**: дублирование, длинные методы
- 📊 **Метрики сложности**: цикломатическая сложность
- 🧪 **Покрытие тестами**: gap analysis
- 📈 **Приоритизация**: что рефакторить в первую очередь

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/legacy-system",
  "template_name": "refactoring",
  "user_query": "Создай детальный план рефакторинга legacy системы с приоритизацией задач"
}
```

#### Результат включает:
- 📋 Поэтапный план рефакторинга
- ⚡ Оценка сложности и времени
- 🎯 Приоритизация по важности
- 🔧 Конкретные техники рефакторинга

---

### 5. `performance-analysis` - Анализ Производительности ⚡

Выявление узких мест и оптимизация производительности.

#### Анализирует:
- 🐌 **Узкие места**: медленные алгоритмы, запросы
- 💾 **Использование памяти**: утечки, оптимизация
- 🔄 **Циклы и рекурсия**: O(n) сложность
- 🌐 **Сетевые запросы**: кэширование, батчинг
- 📊 **База данных**: индексы, N+1 проблемы
- 🏗️ **Архитектурные решения**: масштабируемость

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/high-load-service",
  "template_name": "performance-analysis",
  "user_query": "Найди узкие места и предложи оптимизации для увеличения производительности в 3 раза"
}
```

#### Результат включает:
- 📊 Профиль производительности
- 🎯 Топ узких мест с оценкой влияния
- 🔧 Конкретные оптимизации
- 📈 Ожидаемый прирост производительности

---

Планирование переходов на новые технологии и фреймворки.

#### Планирует:
- 🔄 **Стратегию миграции**: поэтапный переход
- 📦 **Анализ зависимостей**: совместимость, замены
- ⚠️ **Риски и проблемы**: breaking changes
- 🧪 **Тестирование**: regression testing
- 📋 **Чек-листы**: что нужно сделать
- ⏱️ **Временные оценки**: планирование спринтов

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/react-app",
  "template_name": "migration-guide",
  "user_query": "Создай план миграции с React 16 на React 18 с анализом breaking changes"
}
```

#### Результат включает:
- 🗺️ Пошаговый план миграции
- ⚠️ Предупреждения о рисках
- 🔧 Скрипты автоматизации
- ✅ Критерии успешности

---

### 7. `api-documentation` - API Документация 📡

Специализированный шаблон для создания API документации.

#### Создает:
- 🎯 **Endpoint описания**: URL, методы, параметры
- 📝 **Request/Response**: схемы, примеры
- 🔐 **Аутентификация**: токены, OAuth
- ❌ **Коды ошибок**: описание и решения
- 📊 **Rate limiting**: лимиты и политики
- 🔄 **Версионирование**: changes, deprecation

#### Пример использования:
```json
{
  "path": "/Users/developer/Projects/rest-api",
  "template_name": "api-documentation", 
  "user_query": "Создай OpenAPI документацию для REST API с примерами запросов"
}
```

#### Результат включает:
- 📋 OpenAPI/Swagger совместимую документацию
- 💻 Интерактивные примеры
- 🔍 Поиск по endpoints
- 📱 SDK генерация примеры

## 🎨 Кастомизация шаблонов

### Использование параметра `template`

Вы можете создать собственный Handlebars шаблон:

```json
{
  "path": "/path/to/project",
  "template": "# Анализ {{project_name}}\\n\\n{{#each files}}## {{this.path}}\\n```{{this.language}}\\n{{this.content}}\\n```\\n{{/each}}",
  "user_query": "Создай краткий технический обзор"
}
```

### Комбинирование с пользовательскими запросами

Любой шаблон можно дополнить специфическим запросом:

```json
{
  "template_name": "code-review",
  "user_query": "Дополнительно сфокусируйся на React Hooks и современных паттернах"
}
```

## 💡 Лучшие практики

### 1. Комбинирование шаблонов

Для комплексного анализа используйте несколько шаблонов:

```bash
# Сначала общий анализ
get_analyze --template=code-review

# Затем специализированные
get_analyze --template=security-audit --session_id=<session_id>
get_analyze --template=performance-analysis --session_id=<session_id>
```

### 2. Настройка для команды

Создайте стандартные запросы для вашей команды:

```json
{
  "template_name": "code-review",
  "user_query": "Проанализируй согласно нашим coding standards: использование TypeScript, покрытие тестами >80%, ESLint правила, React best practices"
}
```

### 3. Интеграция в CI/CD

Автоматизируйте анализ в pipeline:

```yaml
- name: Security Audit
uses: neira-code-analyzer
with:
  template: security-audit
  
- name: Performance Check  
uses: neira-code-analyzer
with:
  template: performance-analysis
```

## 🚀 Продвинутые возможности

### Шаблоны с фильтрацией

Комбинируйте шаблоны с умными фильтрами:

```json
{
  "template_name": "security-audit",
  "include_patterns": ["**/auth/*", "**/api/*", "**/*security*"],
  "user_query": "Сфокусируйся только на модулях аутентификации и API"
}
```

### Итеративный анализ

Используйте сессии для глубокого исследования:

```json
// Шаг 1: Общий анализ
{
  "template_name": "code-review"
}

// Шаг 2: Углубление в проблемы  
{
  "session_id": "20241214_143022",
  "user_query": "Детально проанализируй найденные проблемы с асинхронностью"
}
```
