# 🤖 Интерактивный AI-анализ кода

**Версия: 2.0**

Это руководство описывает, как использовать ключевую возможность `neira-code-analyzer` — **интерактивные сессии** для глубокого анализа кода и его автоматического исправления.

## 🎯 Концепция интерактивных сессий

Интерактивные сессии позволяют вам вести диалог с ИИ-анализатором. Вы можете начать с общего обзора, а затем задавать уточняющие вопросы, просить более детальный анализ конкретных частей кода или даже давать команды на автоматическое исправление.

Каждая сессия сохраняет контекст вашего диалога, что позволяет ИИ давать более точные и релевантные ответы на последующие запросы.

## 🚀 Управление сессией: параметр `session_id`

Ключ к управлению сессиями — это параметр `session_id` в инструменте `get_analyze`.

| `session_id` | Действие |
|--------------|----------|
| **Не указан или пустой** | 🆕 **Создает новую сессию.** Идеально для начала нового анализа или смены фокуса. |
| **Указан** | 📋 **Продолжает существующую сессию.** Используйте для уточняющих вопросов и углубления анализа. |

---

### Пример 1: Создание новой сессии

Чтобы начать новый анализ, вызовите `get_analyze` **без** `session_id`.

```json
{
  "path": "/path/to/project",
  "template_name": "code-review",
  "user_query": "Проведи общий обзор кода, найди основные проблемы."
}
```

В ответ сервер создаст сессию и вернет ее `session_id`:

```
# 🤖 Автоматический анализ кода

**🆕 Новая сессия создана**
**🆔 Сессия:** `20241215_110030`
...
```

### Пример 2: Продолжение диалога

Чтобы задать уточняющий вопрос, используйте `session_id` из предыдущего ответа.

```json
{
  "path": "/path/to/project",
  "session_id": "20241215_110030",
  "user_query": "Спасибо. Расскажи подробнее о проблеме с N+1 запросом в `users/models.py`."
}
```

## 📦 JSON-контракт: Структурированные ответы

ИИ отвечает в предсказуемом JSON-формате, что позволяет легко интегрировать анализ в другие инструменты.

**Пример ответа от ИИ:**
```json
{
  "status": "suggesting_fixes",
  "analysis_summary": "Обнаружен N+1 запрос в `users.models.User`...",
  "findings": [
    {
      "severity": "high",
      "title": "N+1 Query Problem",
      "file": "src/users/models.py",
      "suggestion": "Использовать `prefetch_related` для оптимизации запросов."
    }
  ],
  "suggested_actions": [
    {
      "action": "fix_issue",
      "path": "src/users/models.py",
      "issue": "N+1 Query",
      "fix_type": "replace",
      "old_code": "queryset = User.objects.all()",
      "new_code": "queryset = User.objects.prefetch_related('profile').all()"
    }
  ],
  "questions_for_user": ["Хотите применить это исправление автоматически?"]
}
```
- **`status`**: Текущее состояние анализа (`analyzing`, `suggesting_fixes`, `completed`).
- **`findings`**: Список обнаруженных проблем.
- **`suggested_actions`**: Список конкретных действий в JSON-формате для автоматического исправления.
- **`questions_for_user`**: Вопросы от ИИ для продолжения диалога.

## 🛠️ Автоматическое исправление кода

`AnalysisActionExecutor` — это компонент, который безопасно выполняет действия, предложенные ИИ.

### Поддерживаемые действия

- `create_file`: Создание нового файла.
- `update_file`: Обновление существующего файла (полная замена).
- `refactor_function`: Рефакторинг конкретной функции.
- `add_comment`: Добавление комментария.
- `fix_issue`: Исправление проблемы (например, замена участка кода).
- `optimize_code`: Оптимизация производительности.

### 🔒 Безопасность — ваш приоритет

- **Защита от Path Traversal:** Все файловые пути, предложенные ИИ, проходят строгую проверку и не могут выйти за пределы директории проекта.
- **Автоматические бэкапы:** Перед каждым изменением файла создается его резервная копия в директории `.neira/backups/<session_id>/`.
- **Возможность отката:** В будущем планируется добавить функцию полного отката всех изменений сессии.
