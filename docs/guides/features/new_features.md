# Новые возможности системы

## 🚀 Интерактивный анализ кода

### Что это?
Новый MCP инструмент `interactive_analysis` для многошагового анализа с сохранением контекста сессий.

### Как использовать?
```json
{
  "session_id": "unique-session-id",
  "analysis_type": "refactoring",
  "code_snippet": "your code here",
  "file_path": "/path/to/file.py"
}
```

### Возможности:
- Управление сессиями анализа
- Автоматические исправления через `AnalysisActionExecutor`
- Рефакторинг и оптимизация кода
- Асинхронная обработка запросов

## 🎯 Автоматическая генерация документации

### Инструмент `gen_docs`
- Создание документации с git-историей
- Автоматическое обновление changelog
- Поддержка версионирования

### Система пресетов `manage_presets`
- Управление конфигурациями фильтров
- Сохранение и загрузка настроек
- Оптимизация под разные проекты

## 🔧 Система фильтрации

### FileSizeFilter
**Константа:** `MAX_FILE_SIZE_KB = 500`  
**Цель:** Исключение больших файлов из анализа

### Агрессивные фильтры
- Исключение кэшей JS/TS фреймворков
- Фильтрация build инструментов
- Очистка временных файлов
- **Результат:** Ускорение анализа на 40-60%

## 📊 Система анализа архитектуры

### 7 профессиональных шаблонов:
1. **code-review** - Ревью кода
2. **security-audit** - Аудит безопасности  
3. **performance** - Анализ производительности
4. **documentation** - Генерация документации
5. **refactoring** - Рефакторинг кода
6. **testing** - Анализ тестирования
7. **architecture** - Архитектурный анализ

### Интеграция с AI
- Централизованный `AIResponseParser`
- JSON контракты вместо text parsing
- Connection pooling для производительности
- Rate limiting (max 5 одновременных запросов)

## 🏗️ Новая архитектура

### От монолита к модулям
- **DocsGenerator** → модульная система
- **FilterSetupService** → интеллектуальная настройка
- **AnalysisAgent** → специализированный агент
- **ServiceContainer** → DI без глобального состояния

### SOLID принципы
- Single Responsibility во всех модулях
- Dependency Injection через контейнер
- Open/Closed для расширений
- Liskov Substitution в наследовании
- Interface Segregation в API
