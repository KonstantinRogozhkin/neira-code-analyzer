# Система конфигурации .neira

## Проблема
Ручная настройка фильтров каждый раз для анализа кода.

## Решение  
Автоматическая конфигурация через файлы `.neira` в корне проекта.

## Использование

### 1. Создание конфигурации
```json
{
  "path": "/path/to/project",
  "preset_name": "python-project"
}
```
Команда `set_filters` создаёт `.neira` файл.

### 2. Автоматическое применение
```json
{
  "path": "/path/to/project"
}
```
Все MCP инструменты (`get_context`, `get_analyze`, `gen_docs`) автоматически применяют сохранённые настройки.

## Форматы

**`.neira`** (JSON) - основной формат:
```json
{
  "include_patterns": ["*.py", "*.md"],
  "exclude_patterns": ["tests/**", "__pycache__/**"],
  "template_name": "code-review"
}
```

**`.neiraignore`** - простые исключения (как .gitignore):
```
__pycache__/
*.pyc
node_modules/
```

## Приоритет
1. Пользовательские параметры
2. `.neira` файл  
3. Значения по умолчанию

## Командная работа
Добавьте `.neira` в git для единых настроек в команде.
