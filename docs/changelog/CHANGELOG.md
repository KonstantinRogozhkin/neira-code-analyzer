# Changelog

Все значимые изменения в проекте neira-code-analyzer документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased] - 2024-12-13

### 🚀 Добавлено
- **Система архитектурной документации**: Создан детальный обзор архитектуры с схемами компонентов
- **Документ улучшений кода**: CODE_IMPROVEMENTS.md с рекомендациями по рефакторингу
- **Централизованная обработка ошибок**: Новые exception классы и глобальный обработчик
- **Автоматическая генерация документации**: Инструмент `gen_docs` для поддержания актуальности
- **Файл игнорирования**: .neiraignore для исключения бинарных файлов из анализа
- **Система тестирования**: Создана полноценная директория `tests/` с модульными и интеграционными тестами
- **Test coverage**: Добавлены тесты для всех новых компонентов (test_analysis_action_executor.py, test_analysis_agent.py, etc.)
- **CI/CD Pipeline**: GitHub Actions workflow с проверками качества (Ruff, mypy) и безопасности (pip-audit)
- **FileSizeFilter**: Новый фильтр по размеру файлов с константой `MAX_FILE_SIZE_KB = 500`
- **Интерактивный анализ**: Инструмент `interactive_analysis` с управлением сессиями

### 🔧 Изменено
- **Улучшена структура документации**: Реорганизация в docs/ с INDEX.md навигацией
- **Обновлен CONTRIBUTING.md**: Подробные инструкции для разработчиков
- **Расширен анализ архитектуры**: Добавлены компоненты безопасности и масштабируемости
- **Асинхронность**: Удалена устаревшая синхронная функция `generate_ai_review()`, используется только `generate_ai_review_async()`
- **AI Response parsing**: Централизованный `AIResponseParser` заменил дублированный код
- **Архитектура**: Внедрены принципы SOLID, модульность и расширяемость

### 🐛 Исправлено
- **Проблема с бинарными файлами**: Исключение *.so файлов из анализа
- **Ошибки MCP фильтров**: Корректная обработка директории .neira
- **Валидация путей**: Улучшенная проверка существования файлов
- **Path Traversal защита**: Устранена уязвимость в action_executor.py и analysis_action_executor.py
- **Валидация путей**: Добавлена функция `_validate_file_path()` для предотвращения выхода за пределы проекта
- **Security monitoring**: pip-audit интегрирован в CI, статус: 0 уязвимостей

### 📚 Документация
- Создана архитектурная схема системы
- Добавлены рекомендации по CI/CD
- Описаны принципы безопасности
- Планы развития на 6+ месяцев

## [2.0.0] - 2024-12-12

### 🚀 Добавлено
- **Интерактивный анализ кода**: Новый инструмент `interactive_analysis` с поддержкой сессий
- **Система управления сессиями**: AnalysisSessionManager для многошагового анализа
- **Исполнитель действий анализа**: AnalysisActionExecutor для автоматических исправлений
- **Централизованный парсер ответов**: AIResponseParser для унификации обработки AI
- **Комплексная система тестирования**: Полное покрытие новых компонентов тестами
- MCP инструмент `gen_docs` для автоматической генерации документации с git-history changelog
- Система автоматической конфигурации через файлы `.neira` и `.neiraignore`
- Централизованный `AIResponseParser` для унификации обработки AI ответов
- Новые архитектурные компоненты: `AnalysisAgent`, `AnalysisSessionManager`
- Улучшенный `AnalysisActionExecutor` с поддержкой рефакторинга и оптимизации

### 🔒 Безопасность
- **Исправлена уязвимость Path Traversal**: Валидация файловых путей в action_executor
- **Улучшена изоляция процессов**: Безопасное выполнение Rust компонента
- **Валидация входных данных**: Проверка всех пользовательских параметров

### 🔧 Изменено
- **Архитектура MCP сервера**: Расширение до 14+ инструментов
- **Асинхронная обработка**: Полный переход на async/await паттерн
- **Модульная структура**: Разделение ответственности между компонентами
- **Рефакторинг от God Object к SOLID архитектуре**
- **Реализация JSON контрактов с AI вместо хрупкого text parsing**
- **Полное применение Single Responsibility Principle**
- **Достигнут 100% success rate тестов**

### ❌ Удалено  
- **Устаревшие синхронные функции**: generate_ai_review() заменена асинхронной версией
- **Дублирование кода**: Консолидация логики парсинга в AIResponseParser
- **Мертвый код**: Очистка неиспользуемых импортов и функций
- **Устаревшие файлы**: Очистка от мертвого DI-контейнера и sys.path хаков
- **Синхронные блокировки**: Убраны функции блокирующие event loop

## Соглашения

### Типы изменений
- 🚀 **Добавлено** - новая функциональность
- 🔧 **Изменено** - изменения в существующей функциональности  
- ❌ **Удалено** - удаленная функциональность
- 🐛 **Исправлено** - исправления ошибок
- 🔒 **Безопасность** - исправления уязвимостей
- 📚 **Документация** - изменения только в документации

### Версионирование
- **MAJOR** (X.0.0) - несовместимые изменения API
- **MINOR** (0.X.0) - новая функциональность с обратной совместимостью
- **PATCH** (0.0.X) - исправления ошибок с обратной совместимостью

### Git теги
Каждая версия помечается git тегом в формате `vX.Y.Z` (например, `v2.0.0`).
