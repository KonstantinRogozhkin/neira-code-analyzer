# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Централизованный `AIResponseParser` для унификации парсинга ответов ИИ.
- Улучшена реализация методов-заглушек в `AnalysisActionExecutor` с базовой логикой рефакторинга и исправления кода.

### Changed
- `DocsAgent` теперь использует асинхронный `generate_ai_review_async`.

### Fixed
- **Безопасность:** Добавлена валидация путей файлов в `AnalysisActionExecutor` и `ActionExecutor` для предотвращения Path Traversal атак.
- Удалена устаревшая синхронная функция `generate_ai_review` из `ai_utils.py`.

## [2.0.0] - 2024-12-14

### Added
- **Интерактивная модель анализа:**
    - `AnalysisAgent`: Главный оркестратор для управления сессиями.
    - `AnalysisSessionManager`: Управление жизненным циклом сессий.
    - `AnalysisActionExecutor`: Безопасное выполнение действий (`create_file`, `update_file`).
    - `BaseSessionManager`: Базовый класс для устранения дублирования кода.
- **JSON API Contract:** Взаимодействие с ИИ через строго структурированные JSON-ответы.
- **Асинхронные вызовы ИИ:** Переход на `async` для неблокирующих операций и повышения производительности.
- **Комплексный Test Suite:** (`pytest`, `pytest-asyncio`) для unit, integration и regression тестов.
- **Декларативная регистрация инструментов:** Упрощено добавление новых инструментов через `TOOL_HANDLERS`.
- **Система пресетов для фильтров:** Управление и переиспользование конфигураций фильтров.
- **Автоматический AI анализ (`get_analyze`):** Комплексный анализ кода с автоматической оптимизацией.
- **Детальная статистика по файлам и токенам:** Инструмент `analyze_filters` для глубокого анализа.
- **Генератор документации (`gen_docs`):** Инструмент для автоматического создания и обновления документации.

### Changed
- **Архитектура:** Масштабный рефакторинг с переходом на асинхронную, интерактивную модель и отказ от DI-контейнера.
- **Анализ фильтров:** `ContextGenerator` разделен на `FilterAnalyzer` и `AnalysisReporter` (SRP).
- **Миграция на Google AI/Gemini:** Полный переход на API Google Gemini для анализа. (e6075af)
- **Оптимизация фильтров:** Добавлены исключения для современных frontend-фреймворков (`pnpm`, `turbo`, `sveltekit`, etc.).
- **Кеширование:** Добавлено кеширование сервисных объектов для улучшения производительности.
- **API:** Переименование `code_review` → `get_analyze` для ясности. (07c9bd5)

### Fixed
- **Устранены "Silent Failures":** Внедрен Fail-Fast подход с `ConfigurationError` для немедленного оповещения о критических ошибках.
- **Безопасность путей:** Использование `pathlib.Path.is_relative_to()` вместо `startswith` для предотвращения Path Injection.
- **Удален мертвый код:** Полностью удален старый DI-контейнер (`container.py`) и `sys.path` хаки.
- **Исправлена сборка Docker:** Заменена небезопасная `PYTHONPATH` на `pip install -e .`. (1ce36e0)
- **Рефакторинг `docs_generator.py`:** God Object разделен на 4 класса по принципу SRP. (3ccee43)
