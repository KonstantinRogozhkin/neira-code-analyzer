# neira-code-analyzer

MCP сервер для продвинутого анализа кодовых баз с профессиональными шаблонами анализа и мощными инструментами оптимизации фильтров.

## 🎯 Возможности

**6 мощных инструментов для работы с кодом:**

1. **🤖 `get_analyze`** - Автоматический AI анализ кода (⭐ **Флагманская функция**)
   - Полностью автоматизированный анализ кода с Google Gemini
   - Интеллектуальная оптимизация фильтров для соблюдения лимитов токенов
   - Многоступенчатый процесс: анализ структуры → оптимизация → извлечение → AI-анализ
   - Сохранение результатов в версионированную структуру файлов

2. **🎯 `set_filters`** - Автоматическая настройка фильтров проекта (🔧 **Рекомендуется сначала**)
   - Автоопределение типа проекта (Python, React, Electron, etc.)
   - Применение оптимальных пресетов фильтров
   - Сохранение конфигурации в `.neira` для повторного использования
   - Интеграция с другими инструментами анализа

3. **📄 `get_context`** - Генерация контекста для ИИ анализа
   - 7 профессиональных шаблонов (code-review, security-audit, документация и др.)
   - Гибкая фильтрация с glob-паттернами
   - Подсчет токенов для разных LLM

4. **📚 `gen_docs`** - Автоматическая генерация и обновление документации (🆕 **NEW!**)
   - Сканирование проекта на сырые материалы (отчёты, длинные файлы)
   - Извлечение знаний по принципу "проблема → решение → результат"
   - Автоматическое структурирование документации в docs/
   - Создание changelog из git-истории
   - Сжатие руководств до целевой длины (≤150 строк)
   - Архивирование обработанных материалов

5. **🎛️ `manage_presets`** - Управление пресетами фильтров
   - Просмотр, создание, удаление, экспорт/импорт конфигураций фильтров.
   - Позволяет сохранять удачные комбинации для повторного использования.

6. **📋 `get_templates`** - Просмотр доступных шаблонов анализа
   - Получение списка доступных шаблонов с описаниями.

## О проекте

neira-code-analyzer использует высокопроизводительную Rust библиотеку [code2prompt-rs](https://github.com/mufeedvh/code2prompt) для анализа кодовых баз и создания структурированных резюме, оптимизированных для потребления ИИ.

## ⚙️ Установка

neira-code-analyzer это **MCP (Model Context Protocol) сервер**, который интегрируется с LLM клиентами через стандарт MCP.

### Установка зависимостей

```bash
# Клонируйте репозиторий
git clone https://github.com/odancona/neira-code-analyzer.git
cd neira-code-analyzer

# Установите зависимости (поддерживается uv и rye)
uv sync
# или
rye sync
```

## 🚀 Быстрый старт

### 1. Подключение MCP сервера

Добавьте сервер в конфигурацию вашего MCP клиента:

```json
{
  "servers": {
    "neira-code-analyzer": {
      "command": "uv",
      "args": ["run", "python", "-m", "src.neira_code_analyzer.main"],
      "cwd": "/path/to/neira-code-analyzer"
    }
  }
}
```

### 2. Пример использования set_filters (🔧 Рекомендуется сначала)

```json
{
  "path": "/Users/username/Projects/my-project"
}
```

☝️ **Совет:** Начните с `set_filters` для автоматической настройки оптимальных фильтров

### 3. Пример использования gen_docs (🆕 Новинка!)

```json
{
  "path": "/Users/username/Projects/my-project",
  "docs_structure": "standard",
  "scan_depth": 3,
  "max_file_size": 400,
  "archive_processed": true,
  "update_changelog": true,
  "git_scan_days": 14,
  "compress_guides": true,
  "target_guide_length": 150
}
```

### 4. Пример использования get_analyze (⭐ Рекомендуется)

```json
{
  "path": "/Users/username/Projects/my-project",
  "template_name": "code-review",
  "include_patterns": ["*.py", "*.js"],
  "exclude_patterns": ["tests/**", "node_modules/**"],
  "max_tokens": 500000,
  "ai_model": "gemini-2.5-pro-preview-06-05"
}
```
