# neira-code-analyzer

**Версия 2.0**

MCP-сервер для продвинутого анализа кодовых баз с **интерактивными AI-сессиями**, профессиональными шаблонами и мощными инструментами оптимизации фильтров.

## 🎯 Ключевые возможности

1.  **🤖 `get_analyze`** - Интерактивный AI-анализ кода (⭐ **Флагманская функция**)
    -   Ведите диалог с ИИ для глубокого анализа (`user_query`).
    -   Получайте структурированные ответы в формате **JSON**.
    -   **Автоматическое исправление кода**: ИИ может сам применять исправления.
    -   Поддержка Google Gemini (`gemini-2.5-pro`).
    -   Безопасность: автоматические бэкапы перед внесением изменений.

2.  **🔧 `set_filters`** - Автоматическая настройка фильтров  
    -   Автоматическое определение типа проекта и применение оптимальных фильтров.
    -   Агрессивное исключение ненужных файлов для экономии токенов.
    -   Сохранение конфигурации в .neira файлах для повторного использования.

3.  **📄 `get_context`** - Генерация контекста для ИИ
    -   Профессиональные шаблоны (`code-review`, `security-audit`, `documentation` и др.).
    -   Гибкая фильтрация с glob-паттернами.
    -   Точный подсчет токенов.

4.  **🎛️ `manage_presets`** - Управление пресетами фильтров
    -   Создание, редактирование и удаление пресетов для разных типов проектов.
    -   Экспорт/импорт конфигураций между проектами.

5.  **📋 `get_templates`** - Просмотр доступных шаблонов
    -   Получение списка всех доступных шаблонов анализа.

6.  **📝 `gen_docs`** - Автоматическая генерация документации
    -   Анализирует проект и создает или обновляет документацию.
    -   Использует git-историю для автоматического обновления `CHANGELOG.md`.

## ⚙️ Установка

```bash

git clone https://github.com/odancona/neira-code-analyzer.git
cd neira-code-analyzer

# Установите зависимости (требуется uv)
uv sync
```

## 🚀 Быстрый старт

### 1. Подключение MCP сервера

Добавьте сервер в конфигурацию вашего MCP-клиента:

```json
{
  "servers": {
    "neira-code-analyzer": {
      "command": "uv",
      "args": ["run", "python", "-m", "src.neira_code_analyzer.main"],
      "cwd": "/path/to/neira-code-analyzer"
    }
  }
}
```

### 2. Пример использования get_analyze (⭐ Рекомендуется)

**Создание новой сессии (НЕ указывайте session_id):**
```json
{
  "path": "/Users/username/Projects/my-project",
  "template_name": "code-review",
  "include_patterns": ["*.py", "*.js"],
  "exclude_patterns": ["tests/**", "node_modules/**"],
  "max_tokens": 500000,
  "ai_model": "gemini-2.5-pro-preview-06-05",
  "user_query": "Проведи детальный анализ с фокусом на производительность"
}
```

**Продолжение существующей сессии (укажите session_id):**
```json
{
  "path": "/Users/username/Projects/my-project",
  "session_id": "20241213_143022",
  "user_query": "Теперь проанализируй модуль авторизации"
}
```
